================================================================================
                    LEARNAPP / LMS - DEPLOYMENT GUIDE (RENDER)
================================================================================

This guide covers complete step-by-step instructions to deploy both the Backend
(FastAPI) and Frontend (React/Vite) on Render.

--------------------------------------------------------------------------------
STEP 1: COMMIT & PUSH LOCAL FIXES TO GITHUB
--------------------------------------------------------------------------------
Run these commands in your project root terminal to push the latest fixes:

    git add .
    git commit -m "fix: update db driver configuration and deployment files"
    git push origin main

--------------------------------------------------------------------------------
STEP 2: DEPLOY BACKEND ON RENDER (WEB SERVICE)
--------------------------------------------------------------------------------
1. Log in to Render Dashboard (https://dashboard.render.com).
2. Click "New +" and select "Web Service".
3. Connect your GitHub repository (`learnapp`).
4. Configure the Web Service settings:
   - Name:            learnapp-backend (or your preferred name)
   - Region:          Choose the region closest to your database (e.g., Singapore, Frankfurt, Ohio)
   - Branch:          main
   - Root Directory:  backend
   - Runtime:         Python 3
   - Build Command:   pip install -r requirements.txt
   - Start Command:   uvicorn app.main:app --host 0.0.0.0 --port $PORT

5. Add Environment Variables (under "Environment" tab):
   -----------------------------------------------------------------------------
   VARIABLE NAME       VALUE / DESCRIPTION
   -----------------------------------------------------------------------------
   PYTHON_VERSION      3.12.8
   DATABASE_URL        mysql+pymysql://<USER>:<PASSWORD>@<HOST>:<PORT>/<DB_NAME>
   JWT_SECRET_KEY      <generate a 32+ character secure random secret>
   JWT_ALGORITHM       HS256
   JWT_EXPIRE_MINUTES  60
   ENVIRONMENT         production
   DEBUG               False
   CORS_ORIGINS        https://<your-frontend-service>.onrender.com,http://localhost:5173
   RATE_LIMIT_ENABLED  True
   UPLOAD_DIR          uploads
   -----------------------------------------------------------------------------
   * NOTE ON DATABASE_URL:
     If your database provider gave you a URL starting with `mysql://`, the code 
     automatically handles it, but using `mysql+pymysql://` explicitly is recommended.

6. Click "Create Web Service".
   Wait for the deployment to finish. Once live, note your backend URL:
   e.g., https://learnapp-backend.onrender.com

7. Run Database Migrations (One-time or after schema changes):
   - In Render Dashboard, open your backend service.
   - Go to the "Shell" tab.
   - Run:
       alembic upgrade head
   - Optional: Seed sample data:
       python seed.py

--------------------------------------------------------------------------------
STEP 3: DEPLOY FRONTEND ON RENDER (STATIC SITE)
--------------------------------------------------------------------------------
1. In Render Dashboard, click "New +" and select "Static Site".
2. Connect your GitHub repository (`learnapp`).
3. Configure settings:
   - Name:               learnapp-frontend
   - Branch:             main
   - Root Directory:     frontend
   - Build Command:      npm install && npm run build
   - Publish Directory:  dist

4. Add Environment Variable:
   - Key:   VITE_API_BASE_URL
   - Value: https://learnapp-2vx3.onrender.com
     (Your live backend URL, without trailing slash)

5. Configure Single Page Application (SPA) Rewrite Rule:
   - Go to "Redirects / Rewrites" tab in the Static Site settings.
   - Add Rewrite Rule:
       Source:      /*
       Destination: /index.html
       Action:      Rewrite
   - This ensures client-side routing (React Router) works on refresh.

6. Click "Create Static Site".

--------------------------------------------------------------------------------
STEP 4: UPDATE CORS ON BACKEND
--------------------------------------------------------------------------------
1. Once your frontend is live (e.g., https://learnapp-frontend.onrender.com):
2. Go to your Backend Web Service -> "Environment" tab.
3. Update `CORS_ORIGINS` to include the live frontend domain:
     CORS_ORIGINS = https://learnapp-frontend.onrender.com
4. Save Changes (Render will automatically re-deploy the backend with the new CORS).

--------------------------------------------------------------------------------
TROUBLESHOOTING & COMMON MISTAKES
--------------------------------------------------------------------------------
1. "error: Read-only file system / maturin failed (pydantic-core)":
   - Caused by Render using Python 3.14 which lacks pre-built wheels.
   - Fixed by keeping PYTHON_VERSION=3.12.8 in Render Environment variables and
     having 3.12.8 in .python-version and runtime.txt.

2. "ModuleNotFoundError: No module named 'MySQLdb'":
   - Caused by SQLAlchemy defaulting to the C mysqlclient driver when given mysql://.
   - Fixed by normalizing the URL to mysql+pymysql:// and installing PyMySQL as MySQLdb.

3. React Router 404 on page refresh:
   - Ensure the SPA rewrite rule (/* -> /index.html) is added under Render Static Site settings.
